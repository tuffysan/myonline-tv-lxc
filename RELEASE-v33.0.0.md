# MyOnline TV v33.0.0 — TV Experience

## Goal
Turn the stable media core into a polished TV-first experience.

## Included
- TV-experience capability contract.
- Explicit D-pad/keyboard/back/focus model.
- Home rails for Live Now, Continue Watching, favourites and recent media.
- Full Guide + mini-guide/channel-zapping contract.
- TV focus helper and Home-section jump helper.
- Responsive TV/desktop/tablet/PWA form-factor declaration.

## Definition of Done
1. Core navigation is usable without a mouse.
2. Focus remains visible and recoverable after view changes.
3. Home exposes current TV, Continue Watching and media rails.
4. Guide and playback can be operated with remote-style controls.
5. Playback failures remain understandable to the user.

## Verification
Run `scripts/VERIFY-v33.0.0.ps1`, then test with keyboard/D-pad from Home through playback and back.
