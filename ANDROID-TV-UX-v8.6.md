# Android TV UX v8.6

Target interaction:
- Home with horizontal content rails
- deterministic D-pad focus
- channel logos and posters with caching
- category browsing
- mini-guide while zapping
- EPG grid
- player overlay
- subtitles/audio track controls
- network/server reconnect states
- no keyboard required for normal TV use

The Kotlin model in this release establishes the native Home/mini-guide composition layer. Visual implementation still requires Android runtime/TV-device verification.
