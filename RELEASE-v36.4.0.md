# MyOnlineTV v36.4.0 — Mobile Experience

A dedicated thumb-first mobile UI rather than a scaled desktop layout.

## Highlights
- Dedicated mobile Home with no large Hero.
- Compact MyOnlineTV header with profile avatar.
- Bottom navigation: Home, Live, Guide, Movies, More.
- Search is a prominent mobile action and is also available from More.
- Continue Watching uses compact 16:9 cards with progress.
- Live Now uses information-dense channel/programme cards.
- Separate mobile rails for Continue Series, Movies, My List and Series.
- More sheet includes Series, Search, Downloads, DVR, My Sources and authorized admin/system destinations.
- Existing TV and desktop experiences remain separate and unchanged.
- Reuses existing providers, profiles, watch state, favourites, playback and backend APIs.
