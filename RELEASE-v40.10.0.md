# MyOnlineTV v40.10.0 — Player Experience

Focus: polish the VOD player controls while preserving the contained player layout and the playback engines from v40.9.0.

## Changes
- Dedicated ±10 second controls.
- Mute/unmute and volume control.
- Playback speed selector: 0.75×, 1×, 1.25×, 1.5× and 2×.
- Existing keyboard shortcuts, fullscreen, buffered timeline, Instant Seek, Playback Reliability and Adaptive Buffer remain intact.
- Mobile keeps a compact control surface.
- Release regression tests guard the controls and contained desktop geometry.
