Fixes missing Adult/18+ controls in My Sources > Edit IPTV > Live TV and improves visibility into provider imports.

- Added All / Adult (18+) / Active / Inactive group filters.
- Added live "shown of total" match count.
- Added Select matches / Uncheck matches bulk actions.
