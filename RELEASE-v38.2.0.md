# MyOnline TV v38.2.0 — Adaptive Navigation & Focus

Navigation refinement across phone, tablet, desktop and TV.

## Highlights
- Per-view navigation context remembers focus and scroll position.
- Back restores the user's previous context instead of only the previous page.
- TV focus is restored and automatically scrolled into view.
- Stronger, consistent focus-visible treatment for remote/keyboard navigation.
- Mobile More is grouped into Watch, Library and Settings.
- Tablet landscape gains an adaptive compact navigation rail.
- Orientation changes preserve the current view and navigation state.
- Existing permission/navigation configuration remains the source of truth.
