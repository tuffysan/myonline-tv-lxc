# MyOnlineTV v35.0.0 — Unified Media Experience

This is the product/UI release that establishes one MyOnlineTV design language across TV, desktop, tablet and mobile.

## Highlights
- Cinematic, media-first Home screen.
- Direct Watch Live and Guide entry points.
- Universal search promoted to primary mobile navigation.
- Responsive content rails and richer Live Now cards.
- Dedicated ten-foot focus and sizing rules for remote-controlled screens.
- Thumb-first mobile shell with persistent bottom navigation.
- Existing backend/API behavior remains compatible.
