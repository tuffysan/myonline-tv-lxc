# MyOnline TV v10

v10 is the intended mature platform baseline.

Core architecture:
- ASP.NET Core/.NET 10 server
- Web/PWA
- Android TV
- Source Engine
- Unified Playback Engine
- device/pairing model
- realtime remote/multi-room protocol
- metadata matching
- DVR 2.0
- operations/recovery
- hardened release process

A package number alone is not proof of production readiness. v10 should only be promoted as stable after the v9.9 release gate passes in CI and on a real/disposable LXC plus Android TV runtime test.
