# v3.0.2 — Consumer navigation cleanup

The main navigation is for watching and finding media. Administrative/system capabilities no longer appear as viewer destinations.

## Main navigation
Home, Live TV, Guide, Movies, Series, Plex/Jellyfin when configured, Downloads, Recordings/DVR, Alerts, Rooms, Library, Search, plus existing admin-only System/Admin entries.

## Admin
Admin now contains a **System tools** section:
- System overview (previously Platform)
- Diagnostics
- Appliance

## Profile Sync
Profile Sync has no normal menu entry. Its APIs and implementation remain available so profile state can work as background functionality.
