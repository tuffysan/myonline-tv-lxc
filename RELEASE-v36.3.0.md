# MyOnlineTV v36.3.0 — Desktop Home Redesign

Desktop/laptop Home is redesigned as a fast content browser instead of a promotional Hero page.

## Highlights
- No large desktop Hero.
- No permanent right-side Up Next column.
- Search is integrated into the desktop top bar.
- Continue Watching, Live Now, My List, Recently Added Movies and Continue Series are visible as compact rails.
- TV keeps the cinematic v36.1 Home experience.
- Tablet/mobile behavior is preserved.
