# MyOnline TV v35.3.0 — TV Guide Experience

A guide-first release focused on fast programme discovery across TV, desktop, tablet and mobile.

## Highlights
- Denser 30-minute EPG timeline with sticky channel and time headers.
- Prominent live Now marker and Jump to Now action.
- Ten-foot/D-pad friendly programme focus and navigation.
- Programme detail sheet with Watch, Record, Record series and Reminder actions.
- Local browser reminders with Notification support when permitted.
- Existing DVR scheduling and live playback paths are reused rather than replaced.
- Responsive guide layouts for TV, desktop/tablet and phone.

## Release invariants
- VERSION remains the single product-version source.
- Existing PUBLISH, GitHub Release and Proxmox install/update pipeline is unchanged.
