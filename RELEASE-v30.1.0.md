# v30.2.0 — Personal Sources & First Login Guide

- IPTV, Plex and Jellyfin are private per user and cannot be shared.
- Every authenticated user can manage only their own connections.
- First login launches a guided IPTV/Plex/Jellyfin setup.
- Setup completion is persisted per user and requires at least one personal source.
- Existing credentials remain encrypted server-side.
- Zero mandatory recurring/runtime cost.
