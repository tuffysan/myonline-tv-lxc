# MyOnline TV v35.2.0 — Movies & Series Experience

v35.2.0 turns the existing VOD and series catalogue into a media-first browsing experience while preserving the proven v35.1.0 release/deployment pipeline.

## Highlights
- Cinematic movie and series details
- Sort/search improvements for large catalogues
- Watched and favourite state directly in movie browsing
- Season tabs and redesigned episode cards
- Start/continue series and next-unwatched episode
- Responsive layouts for TV, desktop, tablet and mobile

## Release path
Run `PUBLISH.cmd`. GitHub Actions builds the Linux x64 release. Existing Proxmox installations update with `update-from-github.sh` and default to the latest stable GitHub Release.
