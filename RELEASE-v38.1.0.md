# MyOnline TV v38.1.0 — Navigation Reliability

A navigation-only reliability release based directly on v38.0.0.

## Changes
- One shared navigation visibility source for phone, tablet, desktop and TV.
- Mobile More is generated dynamically from the actual configured navigation.
- Alerts, Rooms, Library, System overview, Diagnostics and Appliance remain reachable when enabled and permitted.
- Navigation Manager visibility/order is honored by compact navigation.
- Active view highlighting is consistent across sidebar, bottom navigation and More.
- Phone/tablet header shows the current page and an explicit Back button.
- TV Escape, Backspace and BrowserBack return to the previous app view instead of always jumping Home.
- Navigation history is bounded and falls back safely to Home.
- Side navigation scrolls when the available screen height is too small.
- Admin-only, profile-policy and media-library availability rules are reused consistently.
