# MyOnline TV v36.5.6 — Mobile & Tablet Scroll Fix

This maintenance release fixes touch scrolling on mobile and tablet without changing the desktop or TV experience.

## Fixed

- Vertical page scrolling on phones.
- Vertical page scrolling on tablet portrait and landscape.
- Mobile bottom navigation no longer interferes with page scrolling.
- Horizontal media rails keep independent horizontal touch scrolling.
- Live channel selector keeps its own vertical scrolling.
- Safe-area padding is preserved for mobile devices.

Includes the v36.5.5 direct Release-ID GitHub release workflow.
