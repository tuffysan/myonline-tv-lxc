# MyOnline TV v37.0.0 – Library Management & Provider Refresh

This release adds a dedicated Library Management workspace to Admin. Manage IPTV groups and channels, Movie and Series categories/items, persistent hide rules, bulk actions, provider refresh with a diff summary, and per-group stream quality rules.

Quality detection supports RAW, 4K/UHD, FHD/1080p, HD/720p, SD and Unknown. Each group can select allowed qualities, enable Best available only, and define its own priority order.

The Cleanup Center identifies duplicate-looking channel variants, missing logos and ungrouped channels before you make changes.
