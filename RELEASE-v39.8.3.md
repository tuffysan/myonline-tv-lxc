# v39.8.3 – Live TV Group Filtering

Built directly on v39.8.2.

- Adds a visible, horizontally scrollable group filter directly in Live TV.
- Adds group search so large IPTV group lists are easier to navigate.
- Shows channel counts per group.
- Adds All Groups, Favourites, Recent and Adult (XXX) quick group filters.
- Adult quick filter appears only when visible Adult groups exist.
- Remembers the selected Live TV group per profile and IPTV provider.
- Search continues to filter channels inside the selected group.
- Alt+Left / Alt+Right switches between groups from the keyboard.
- Does not reload the IPTV provider when switching groups; it filters the already cached channel list.
