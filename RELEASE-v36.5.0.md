# MyOnline TV v36.5.0 – Tablet Experience

A dedicated touch-first tablet interface for 720–1179 px screens.

## Highlights
- Purpose-built tablet Home surface.
- Compact side navigation in landscape; bottom navigation in portrait.
- Search-first tablet header.
- Continue Watching landscape rail.
- Two-column Live Now grid.
- Continue Series, Movies, My List and Series rails sized for tablet touch interaction.
- No changes to the TV, desktop or phone-specific Home experiences.
