# v6.3.0 — TV Experience

- Adds a common Android TV UI-state contract for focus, category, mini-guide and channel-number entry.
- Adds recent-channel memory for faster zapping.
- Establishes the TV UX release boundary: artwork/logos, rails, categories, EPG grid and player overlay belong to this layer.
- Keeps playback/server contracts from v6.2.0 unchanged.
- This is the first cumulative TV-experience release; full artwork networking and a complete visual EPG grid still require Android runtime implementation/testing.
