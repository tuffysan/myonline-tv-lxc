# MyOnline TV v36.2.1 — Laptop Layout Fix

A focused responsive-layout update for the v36.2 Desktop Home Experience.

## Changes

- Smaller Continue Watching cards on laptop-sized desktop viewports.
- 16:9 artwork with capped image height to prevent oversized rows.
- Shorter cinematic hero on laptop and low-height browser windows.
- Tighter spacing and more compact Live Now cards.
- Extra compact treatment for screens around 1366×768.
- No change to TV, tablet, mobile, playback, provider, profile, publish or Proxmox update behaviour.

The runtime version continues to come from the repository `VERSION` file through the existing build/backend/UI version chain.
