# MyOnline TV v36.1.0 – TV Home Experience

v36.1.0 turns the television Home screen into a content-first streaming surface while preserving the existing MyOnline TV backend and deployment pipeline.

## Highlights
- Cinematic TV hero driven by profile content.
- Continue Watching rail with progress.
- Live Now rail using current EPG data.
- My List, Movies and Series rails.
- Remote-first focus, horizontal browsing and 10-foot typography.
- Existing desktop/mobile Home remains unchanged.
- Uses existing profile sync, favourites, unified media and playback APIs.
