# MyOnline TV v20 — Long-term Platform

Principles:
1. Zero mandatory runtime cost generated by MyOnline TV.
2. Credentials and provider secrets stay server-side.
3. Web, TV and mobile clients use one platform API.
4. Paid/cloud integrations are optional and disabled by default.
5. Local-first discovery, automation and monitoring.
6. Stable plugin/provider API.
7. Upgrade, health check and rollback are first-class.
8. No release is considered production-ready until CI and real LXC/client tests pass.

v20 is a cumulative long-term architecture milestone, not proof that every optional client/provider is fully implemented.
