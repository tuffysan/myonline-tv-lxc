# v6.1.0 — Android TV Client Foundation

- Starts the first native Android TV / Google TV client in `clients/android-tv`.
- Adds TV launcher metadata, D-pad-friendly login/focus flow and server configuration.
- Adds cookie/session-capable MyOnline TV API client.
- Adds health/login and initial Live/Guide/Movies/Series hooks.
- Adds native Media3/ExoPlayer HLS player activity.
- Keeps IPTV/Plex/Jellyfin credentials on the server.
- Web/PWA and LXC server remain cumulative from v6.0.0.
- Android APK build is not claimed as verified in this environment.
