# MyOnline TV v35.1.0 — Live TV Experience

This release builds directly on the verified v35.0.3 publish/deploy baseline.

Highlights: TV-first Live navigation, faster channel zapping controls, Now/Next and mini-guide workflow, favourites/recent shortcuts, numeric tuning, mobile swipe channel switching, media remote integration, and guarded stream recovery.

Deployment: publish with `PUBLISH.cmd`, then update Proxmox with the existing `update-from-github.sh`.
