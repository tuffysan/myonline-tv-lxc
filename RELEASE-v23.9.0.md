# v31.1.2 — Universal Search

One local search domain across TV, EPG, media and recordings.

This is cumulative from v23.8.0. It preserves the zero-mandatory-cost rule and server-side credentials.

**Definition of done:** a capability is not considered finished merely because this release contains a helper or capability API. Provider/device features require UI → API → backend → actual playback/storage/device verification.
